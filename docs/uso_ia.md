RESPUESTA IA: 
La etiqueta <nav> en HTML5 define un bloque de enlaces de navegación, crucial para la accesibilidad y SEO. Se estructura comúnmente dentro de un <header> usando una lista desordenada (<ul>, <li>) para organizar los enlaces (<a>, <li>) para organizar los enlaces (<a>). Es ideal para menús principales, índices o tablas de contenido

html

<nav>
    <ul>
        <li><a href="#inicio">Inicio</a></li>
        <li><a href="#servicios">Servicios</a></li>
        <li><a href="#contacto">Contacto</a></li>
    </ul>
</nav>
